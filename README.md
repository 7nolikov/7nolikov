## Summary

Senior backend engineer, 8 years building and operating cloud-native data platforms in production. Java and Spring professionally, Go for new projects.

**Contributor to the [OSDU Data Platform](https://community.opengroup.org/Dmitrii_Novikov) since 2021** — the open energy-industry data standard. 135 merged upstream merge requests across 31 repositories: core services (Storage, Search, Indexer, Schema, File, Dataset), security and compliance (Entitlements, Legal, Secret), provider libraries for both Google Cloud and Azure, and ingestion.

Named in The Open Group OSDU Forum's **M13 release recognition** in two contribution areas, Core Services and Energy Data Standards.

Day to day: 20+ microservices on Google Cloud and bare Kubernetes, PostgreSQL and MinIO, hybrid-cloud storage abstractions, and the observability needed to operate them.
